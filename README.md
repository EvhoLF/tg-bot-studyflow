# 🌿 StudyFlow

**Учёба в своём ритме.** Telegram-бот для планирования школьных заданий и контроля дедлайнов.

Проект для ученика 8 класса IT-школы: понятная предметная область, настоящий интерфейс с кнопками, Python, база SQLite и автоматические напоминания. Тема работы: **«Разработка Telegram-бота StudyFlow для планирования учебной деятельности и контроля сроков выполнения заданий»**.

## Что умеет бот

- Пошагово добавлять задание: предмет → название → срок → приоритет → заметка → подтверждение.
- Показывать сегодня, ближайшие 7 календарных дней, все активные, просроченные и выполненные задания.
- Открывать карточки, изменять поля, переносить срок, отмечать выполнение и удалять с подтверждением.
- Напоминать, когда до срока осталось не больше суток, не больше часа, и когда срок прошёл.
- Показывать долю выполненных заданий, количество завершённых вовремя и текущих просрочек.
- Хранить данные после остановки, разделять задания разных пользователей, учитывать личный часовой пояс.
- Отключать напоминания и удалять все свои данные через настройки.

Интерфейс полностью на русском. Кнопки встроены в сообщения; при нажатии экран обычно обновляется на месте. Цвет и шрифт определяет приложение Telegram: оформление построено на аккуратных текстах, эмодзи, коротких шагах и понятных действиях.

## Быстрый старт · Windows

Нужен Python **3.11 или новее** с python.org и интернет. Разработка и локальная проверка выполнены на Python 3.14.3. Команды выполняются в PowerShell из папки проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` замените `PASTE_YOUR_TOKEN_HERE` на токен от официального **[@BotFather](https://t.me/BotFather)**:

1. Откройте BotFather → `/newbot`.
2. Имя: `StudyFlow — учебный планировщик`.
3. Придумайте свободный username с окончанием `bot`.
4. Скопируйте полученный токен только в свой `.env`. Не отправляйте его в чат, презентацию или репозиторий.
5. Сохраните файл. Настройте `DEFAULT_TIMEZONE`, если нужно; по умолчанию `Asia/Qyzylorda`.

```powershell
.\.venv\Scripts\python.exe -m studyflow --check
.\.venv\Scripts\python.exe -m studyflow
```

Откройте своего бота в Telegram → **Start / Начать** → проверьте часовой пояс → **＋ Добавить задание**.
Остановка: **Ctrl+C**. При следующих запусках достаточно последней команды. Можно также использовать `./run.ps1`, если выполнение локальных скриптов разрешено; менять политику PowerShell для проекта не требуется.

**Для работы с настоящим Telegram нужен личный токен владельца.** Команда `--check` проверяет наличие токена, настройки и доступность базы, но не проверяет токен через сеть. Токен не включён в проект.

## Попробовать без Telegram

После установки зависимостей ни токен, ни подключение к Telegram не нужны:

```powershell
.\.venv\Scripts\python.exe -m studyflow --demo
.\.venv\Scripts\python.exe -m unittest discover -v
```

`--demo` показывает работу логики в терминале, включая HTML-разметку сообщений. Это не имитация живого Telegram-клиента. Демонстрация использует временную базу и не меняет реальные задания. Тесты тоже не обращаются к Telegram.

```text

```

## Границы проекта

Это персональный планировщик в личных чатах, рассчитанный на школьную демонстрацию и небольшую группу пользователей. Нет интеграции с электронным дневником, распознавания фото, вложений, групповых заданий и веб-панели. SQLite-запросы выполняются синхронно; для большой аудитории потребуются другая организация доступа к базе и управление нагрузкой.

Один токен → **один запущенный экземпляр**. Для получения сообщений используется long polling: публичный IP и открытый порт не нужны. Бот отправляет напоминания только при работающем процессе, наличии интернета и доступности Telegram. Компьютер в режиме сна их не отправляет.

После перезапуска сохраняются задания, настройки и этапы доставленных напоминаний; незавершённый ввод не сохраняется. После простоя отправляется только актуальный этап, а не все пропущенные уведомления. При редком сбое между отправкой сообщения и записью результата в SQLite возможен повтор — абсолютная гарантия «ровно один раз» здесь не заявляется.
